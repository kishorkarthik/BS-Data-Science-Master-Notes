# IITM DS OPEN NOTES

Open source study notes for the IIT Madras BS Data Science and Applications programme, structured and maintained as a documentation site.

## Courses

### Foundation

- [English 2](Foundation/English%202/overview)
- [Mathematics 1](Foundation/Mathematics%201/overview)
- [Programming in Python](Foundation/Programming%20in%20Python/overview)

## Structure

Notes are organized as:

```text
Program > Level > Course > Weeks
```

Each course has an Overview page followed by its weekly notes.

## Usage

Use the sidebar to navigate courses and weeks.

Notes are continuously updated as the course progresses.
